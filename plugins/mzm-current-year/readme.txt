Displays the current year using the WordPress-configured timezone.

== Usage ==

Add the shortcode anywhere WordPress processes shortcodes:

    [mzm-current-year]

For example, `Copyright [mzm-current-year]` renders as `Copyright 2026` during
2026 and updates automatically when the year changes.
